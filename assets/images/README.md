# شعار سكاي سبايك — Sky Spike Logo

## ⚠️ ملف `sky_spike_logo.png` الحالي هو شعار مؤقت (Placeholder)

الملف الموجود الآن **مولّد برمجياً** بألوان العلامة (كحلي `#0B2A5B` + برتقالي `#FF6F00`)
لكي لا يفشل بناء التطبيق بسبب أصل ناقص. **استبدله بالشعار الرسمي.**

## كيفية استبداله

1. جهّز الشعار الرسمي كملف **PNG بخلفية شفافة**.
2. المقاس المفضّل: **1024×1024** بكسل (مربّع تماماً).
3. اجعل الشعار داخل حوالي **80%** من المربّع، مع هامش شفاف حوله —
   لأن أندرويد يقصّ الأيقونة إلى دائرة على بعض الأجهزة.
4. احفظه بنفس المسار والاسم بالضبط:

   ```
   assets/images/sky_spike_logo.png
   ```

5. اعمل commit وpush — لا حاجة لتعديل أي كود:

   ```bash
   git add assets/images/sky_spike_logo.png
   git commit -m "Replace placeholder with official Sky Spike logo"
   git push origin arena/01a03591-sky-spike-app2
   ```

## أين يُستخدم هذا الملف؟

| الاستخدام | المكان |
|---|---|
| الشريط العلوي في كل الشاشات | `lib/widgets/custom_app_bar.dart` |
| بطاقة المعاينة في الإعدادات | `lib/screens/settings/settings_screen.dart` |
| **أيقونة التطبيق على الهاتف** | تُولَّد تلقائياً في `.github/workflows/android.yml` |

الـ GitHub Actions workflow يقرأ هذا الملف ويولّد منه أيقونات أندرويد
بكل المقاسات (`mipmap-mdpi` حتى `mipmap-xxxhdpi`) قبل بناء الـ APK.
فبمجرد استبدال الصورة، تتغيّر أيقونة التطبيق على الهاتف تلقائياً.

## ملاحظة
